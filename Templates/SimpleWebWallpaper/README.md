# 简单网页壁纸模板

这是一个用于测试 WallpaperMac 网页壁纸导入功能的本地 HTML 项目。

## 特点

- 入口文件固定为 `index.html`
- 零外部依赖，不需要网络连接
- 显示当前时间和日期，方便确认页面正在运行
- 带有轻量渐变背景动画，方便确认网页壁纸没有停留在静态截图
- 默认没有声音，适合直接作为桌面壁纸
- 支持深色环境，并会在用户开启“减少动态效果”时停止背景动画

## 导入测试

1. 打开 WallpaperMac。
2. 将本目录拖入主窗口，或通过“导入壁纸”选择本目录。
3. 如果应用询问 HTML 入口文件，选择 `index.html`。
4. 可以分别测试“复制到应用库”和“引用原文件”两种存储方式。
5. 选中导入后的网页壁纸，在检查器中预览并应用到显示器。
6. 使用暂停、继续、静音和重新加载操作验证网页播放器控制。

模板只使用相对路径加载 `styles.css` 和 `script.js`，请保持三个文件位于同一目录。
