# 项目问题与修复评审报告

本目录保存临时性项目评审、问题排查与整体状态报告。它们用于归档和追溯，不参与应用构建、打包或运行时逻辑。

## 归档规则

- 按报告日期建立目录：`YYYY-MM-DD/`。
- 同一主题可包含问题报告、修复评审或项目状态报告。
- 文件名使用稳定的短名称，例如 `bug-report.md`、`fix-review.md`、`project-report.md`。
- 正式用户文档、接口契约和发布说明不应存放在这里。
