# WallpaperMac 图形化界面设计规范

- 版本：v0.1
- 日期：2026-07-18
- 目标平台：macOS 13+
- 实现方向：SwiftUI + AppKit 混合
- 产品定位：个人高频使用的本地桌面壁纸管理工具
- 设计状态：本地设计规范；待获得 Figma 编辑权限后同步

## 1. 设计目标

1. 让用户在几秒内找到并应用壁纸。
2. 让图片、视频、本地 HTML 网页三种来源一眼可辨。
3. 让多显示器分配、文件路径和播放状态始终可见。
4. 使用接近 macOS 系统应用的结构，减少学习成本。
5. 没有素材时保持空白、清晰，不放演示壁纸或虚假内容。

## 2. 信息架构

### 2.1 主窗口

主窗口采用三栏工作台：

| 区域 | 默认职责 | 关键操作 |
| --- | --- | --- |
| 侧边栏 | 分类和显示器导航 | 切换全部、类型、收藏、最近使用和显示器 |
| 内容区 | 浏览壁纸库 | 搜索、筛选、排序、网格/列表切换、选择壁纸 |
| 检查器 | 管理当前选择 | 预览、应用到显示器、播放控制、元信息、维护 |

默认参考尺寸为 `1280 × 820`；最小可用尺寸建议为 `960 × 640`。窗口缩放时优先保证内容区和检查器的可用宽度，侧边栏保持稳定宽度。

### 2.2 侧边栏导航

- 全部壁纸
- 图片
- 视频
- 网页
- 收藏
- 最近使用
- 显示器
  - 内置显示器
  - 外接显示器（按系统名称显示）
- 底部操作
  - 壁纸库位置
  - 设置

侧边栏中的显示器列表应反映系统当前连接状态。显示器断开时保留记录，但标记为“未连接”，不可误显示为仍在应用。

## 3. 视觉令牌

### 3.1 颜色

设计阶段使用语义令牌，不在组件中直接散落颜色值。最终实现可以将这些令牌映射到 SwiftUI `Color` 和 AppKit 外观。

| 令牌 | 语义 | 建议值 |
| --- | --- | --- |
| `background.canvas` | 主窗口背景 | `#1E1E1E` |
| `background.sidebar` | 侧边栏背景 | `#242424` |
| `background.surface` | 卡片、检查器面板 | `#2B2B2B` |
| `background.elevated` | 弹层、sheet 内容 | `#333333` |
| `text.primary` | 主文字 | `#F5F5F5` |
| `text.secondary` | 次级文字 | `#A6A6A6` |
| `text.tertiary` | 辅助文字 | `#747474` |
| `border.subtle` | 弱边框 | `#3B3B3B` |
| `accent.primary` | 选中、主操作、焦点 | `#0A84FF` |
| `state.success` | 已应用、正常 | `#30D158` |
| `state.warning` | 待处理、低电量策略 | `#FF9F0A` |
| `state.error` | 失效、错误 | `#FF453A` |

颜色只用于表达层级和状态，不使用大面积高饱和背景覆盖壁纸预览。

### 3.2 字体

- 主字体：系统字体 `SF Pro`，由 macOS 系统提供。
- 代码、入口文件名、路径：系统等宽字体。
- 页面标题：`title2` 或相近层级，半粗。
- 卡片标题：`body` 或 `callout`，最多两行。
- 元信息：`caption` / `footnote`，使用次级文字色。
- 不通过缩小字体解决布局问题；优先截断、换行或折叠次要信息。

### 3.3 间距、圆角和阴影

- 间距基线：8pt。
- 常用间距：`8 / 12 / 16 / 24 / 32`。
- 控件圆角：`8–10pt`。
- 壁纸卡片圆角：`14pt`。
- 弹层和大面板圆角：`16pt`。
- 阴影仅用于悬浮层和选中预览，主窗口不依赖重阴影区分层级。

## 4. 核心组件

### 4.1 `WallpaperCard`

用途：在网格或列表中表示单个壁纸。

内容：

- 缩略图或网页预览图。
- 类型标识：图片、视频、网页。
- 名称，最多两行。
- 视频时长或网页入口文件名。
- 当前应用显示器标识。
- 收藏按钮和更多操作。

状态：

- `normal`
- `hovered`
- `selected`
- `applying`
- `applied`
- `missing`
- `unsupported`

要求：卡片在失效状态下保留原缩略图（如果存在），并显示失效原因和“重新定位”入口，不使用纯红色整卡覆盖。

### 4.2 `InspectorPanel`

区域：

1. 大预览。
2. 壁纸名称和类型。
3. 显示器分配列表。
4. 播放控制。
5. 元信息。
6. 维护操作。

显示器分配列表必须直接出现于检查器中，不隐藏在二级菜单。

### 4.3 `ImportSheet`

步骤：

1. 拖拽区/文件选择。
2. 文件类型识别。
3. HTML 入口文件确认（仅网页）。
4. 存储模式选择。
5. 目标壁纸库位置确认。
6. 导入进度和结果。

支持的导入反馈：

- 正在扫描。
- 正在复制。
- 正在生成缩略图。
- 导入成功。
- 部分文件失败。
- 入口文件未找到。
- 无权限读取或写入。

### 4.4 `DisplayAssignmentRow`

包含：

- 显示器名称。
- 连接状态。
- 当前壁纸缩略图和名称。
- 当前壁纸类型。
- “应用”或“已应用”状态。
- 显示器断开时的重新连接提示。

### 4.5 状态组件

- `EmptyState`：没有壁纸时只展示简洁说明和添加入口。
- `MissingAssetState`：文件移动/删除后的修复入口。
- `PermissionState`：读写权限不足时说明影响并提供系统设置入口。
- `ImportErrorState`：保留失败文件、失败原因和重试操作。
- `DisconnectedDisplayState`：显示器断开时保留配置但暂停应用操作。

## 5. 交互与可访问性

- 所有主要操作支持键盘焦点和明确焦点环。
- 不能只用颜色区分状态；已应用、失效和断开状态需同时有图标或文字。
- 预览图不可作为唯一的信息来源，名称和类型必须以文本出现。
- 支持减少动态效果：关闭卡片 hover 动画、视频预览动画和不必要的过渡。
- 播放控制按钮需要提供 macOS VoiceOver 可读的标签。
- 拖拽导入必须同时提供文件选择按钮。
- 删除、移除和重新定位操作需要可恢复或明确确认。

## 6. 播放与后台策略

- 视频壁纸默认静音。
- 网页壁纸默认静音，并提供重新加载操作。
- 支持播放/暂停、循环、静音和恢复。
- 电池模式和全屏应用策略由设置控制。
- 屏幕休眠、唤醒和显示器连接变化必须恢复到可解释状态。
- 播放器错误不得导致主管理窗口失去响应。
