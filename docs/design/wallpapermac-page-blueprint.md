## 2. 页面详细蓝图

### P01 首次启动

布局：居中欢迎内容 + 底部步骤指示。

步骤：

1. 欢迎页：介绍图片、视频和本地网页壁纸。
2. 选择壁纸库位置：默认建议目录，可选择自定义目录。
3. 后台行为：登录时启动、电池优化、全屏应用策略。
4. 权限检查：展示当前可用权限和需要用户处理的项目。
5. 完成：进入空库，不创建演示壁纸。

失败处理：权限无法授予时允许继续进入应用，但将受影响功能标记为待处理。

### P02 壁纸库空状态

- 主区域不显示虚假卡片。
- 展示简短说明：“将图片、视频或网页文件夹拖到这里”。
- 提供“添加壁纸”按钮。
- 拖拽进入窗口时显示边框高亮和可接受类型。
- 左侧导航保持完整，显示器列表仍然可见。

### P03 壁纸库主窗口

顶部工具栏：

- 添加壁纸。
- 搜索。
- 类型筛选：全部、图片、视频、网页。
- 状态筛选：已应用、未应用、失效。
- 排序：最近添加、最近使用、名称。
- 网格/列表切换。

网格卡片：

- 默认使用固定宽高比预览。
- 视频显示时长和播放标识。
- 网页显示“网页”和入口文件名。
- 已应用的显示器显示在卡片底部。
- hover 只显示必要的收藏和更多操作。

### P04 壁纸详情检查器

- 上部为大预览。
- 中部为显示器分配列表。
- 视频/网页显示基础播放控制。
- 下部显示尺寸、时长、入口文件、存储模式和路径。
- 失效资源显示原因、重新定位和移除操作。

### P05 导入图片/视频

流程：

1. 文件选择或拖拽。
2. 扫描并按类型分组。
3. 显示待导入数量和无法导入的文件。
4. 选择复制到应用库或引用原文件。
5. 确认目标目录。
6. 显示导入进度。
7. 结果页提供“查看新壁纸”和“查看失败项目”。

### P06 导入网页

流程：

1. 拖入本地网页项目文件夹。
2. 扫描 `index.html` 和可识别入口文件。
3. 找到唯一入口时直接展示预览。
4. 找到多个入口时要求用户选择。
5. 找不到入口时展示手动选择文件。
6. 检查资源读取权限和相对路径。
7. 完成导入并生成网页壁纸卡片。

### P07 显示器管理

- 显示器列表按系统显示名称排列。
- 每行显示连接状态和当前壁纸。
- 可以从显示器页面直接选择壁纸并应用。
- 显示器断开时保留上一次分配，不宣称已应用。
- 新显示器连接后提供“使用默认壁纸”或手动选择。

### P08 设置窗口

设置分组：

- 通用：登录时启动、外观、语言。
- 壁纸库：路径、导入模式、重新扫描、失效资源。
- 播放：默认静音、循环、电池策略、全屏策略。
- 显示器：独立模式、同步模式、适配方式。
- 快捷键：暂停/恢复、下一张、打开管理窗口。

### P09 文件失效维护

- 通过侧边栏状态筛选进入。
- 支持逐项重新定位。
- 支持批量选择后统一重新定位同一目录。
- 无法恢复时显示移除入口。
- 重新定位成功后立即更新卡片和显示器分配状态。

### P10 错误和权限

错误必须包含：发生了什么、影响是什么、下一步如何处理。

覆盖：

- 壁纸库无读取权限。
- 壁纸库无写入权限。
- 文件已移动或删除。
- 视频格式不支持。
- HTML 入口不存在。
- 网页资源加载失败。
- 显示器在应用过程中断开。

## 3. 原型主路径

### 路径 A：首次使用

`P01-欢迎 → P01-选择库位置 → P01-后台偏好 → P01-权限检查 → P02-空库`

### 路径 B：导入图片并应用

`P02-空库 → P05-导入媒体 → P03-新壁纸 → P04-详情检查器 → P07-选择显示器 → 已应用`

### 路径 C：导入本地网页

`P03-主窗口 → P06-选择网页文件夹 → P06-选择入口 → P06-预览 → P04-网页检查器 → 应用`

### 路径 D：修复失效文件

`P03-失效筛选 → P09-资源维护 → 重新定位 → P04-恢复后的详情 → 已恢复`

### 路径 E：显示器断开

`P07-显示器管理 → 断开状态 → P10-提示 → 显示器重新连接 → 恢复分配`

## 4. 不做的交互

- 不在第一版加入远程 URL 壁纸流程。
- 不在空状态中放示例壁纸。
- 不使用不可解释的自动轮播或隐藏播放行为。
- 不把多显示器分配只放在卡片的更多菜单里。
