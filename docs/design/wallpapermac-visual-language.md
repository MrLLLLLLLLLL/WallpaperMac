# WallpaperMac 视觉语言

- 版本：0.2.12
- 状态：已实施
- 适用：主窗口、检查器、队列管理、设置、引导与空状态

## 1. 定位

WallpaperMac 是一个以视觉素材为中心的 macOS 壁纸工作台。界面不是内容本身，而是一张安静的接触印相表：壁纸缩略图是画面中最亮的部分，工具栏、侧栏和检查器退到石墨背景中。

视觉方向：**黄铜接触印相表（Brass Contact Sheet）**。深石墨背景、暖白文字、细线分隔、黄铜色作为唯一的强调信号；标题使用衬线体制造画册感，数值使用等宽字体制造仪表感。

## 2. 颜色

| Token | Hex | 用途 |
|---|---|---|
| `canvas` | `#0F1011` | 内容区背景 |
| `sidebar` | `#131416` | 侧栏背景 |
| `panel` | `#17181A` | 检查器、卡片、输入框表面 |
| `raised` | `#1E2023` | 悬停、次级表面 |
| `hairline` | `#2B2D30` | 常规分隔线与边框 |
| `hairlineStrong` | `#3A3C3F` | 悬停边框 |
| `text` | `#EDE9E2` | 主文字（暖白） |
| `textSecondary` | `#9C9992` | 次级文字 |
| `textTertiary` | `#6E6B65` | 弱化说明 |
| `brass` | `#C8A468` | 选中、主操作、当前页、收藏 |
| `brassDeep` | `#8C7247` | 黄铜按下态、次级黄铜 |
| `brassWash` | `brass @ 12%` | 选中背景 |
| `applied` | `#8FAE7A` | 已应用状态点 |
| `warning` | `#D1A25A` | 断开、隐藏等提示 |
| `danger` | `#C97F76` | 错误与破坏性操作 |

规则：

- 黄铜是信号，不是装饰。每个视图最多一个黄铜主操作。
- 状态点只用小圆点或短文字，不使用大面积绿色/橙色。
- 不使用阴影；层级由表面、细线、留白和字体建立。

## 3. 字体

| 角色 | 字体 | 规格 |
|---|---|---|
| 页面标题 / 空状态标题 | 系统衬线（New York / Songti SC 回退） | 22–26pt，semibold |
| 区块标题 | SF Pro | 11pt，semibold，`tracking 0.6` |
| 正文 / 控件 | SF Pro | 12–13pt，regular/medium |
| 辅助说明 | SF Pro | 10–11pt，regular |
| 数值 / 尺寸 / 页码 | SF Mono | 9–11pt，medium，tabular |

规则：

- 不使用全大写英文标签；中文标签使用正常大小写。
- 数值统一使用等宽数字，便于纵向对齐。
- 标题允许衬线中文回退，不额外加载字体文件。
- 不在标题中单独强调某个词。

## 4. 布局

三栏结构保持不变：侧栏 220pt、内容区自适应、检查器 340pt。顶部工具栏固定 76pt；侧栏与检查器的顶部也使用同一 76pt 基准线；窗口最小宽度 1242pt。

```text
┌──────────────┬──────────────────────────────────┬──────────────────┐
│ 壁纸库        │ 全部壁纸          搜索 筛选 排序  │ 检查器            │
│ 全部壁纸  50  │ 100 个资源  1/9 页               │ ┌──────────────┐ │
│ 图片      32  ├──────────────────────────────────┤ │ 16:9 预览     │ │
│ 视频       9  │ ┌────┐ ┌────┐ ┌────┐ ┌────┐      │ └──────────────┘ │
│ 网页       9  │ │    │ │    │ │    │ │    │      │ 名称              │
│ 收藏       4  │ └────┘ └────┘ └────┘ └────┘      │ 显示器             │
│ 最近使用      │ ┌────┐ ┌────┐ ┌────┐ ┌────┐      │ 播放               │
│ 播放队列   5  │ │    │ │    │ │    │ │    │      │ 资源               │
│ 分组          │ └────┘ └────┘ └────┘ └────┘      │                  │
│ 显示器        │ 本页 12 项           ‹ 1 2 3 ›   │                  │
└──────────────┴──────────────────────────────────┴──────────────────┘
```

### 侧栏

- 选中项：左侧 2pt 黄铜竖条 + 12% 黄铜底色，不使用整块蓝色胶囊。
- 分类行右侧显示等宽计数；分组与显示器同样使用右侧计数或状态点。
- 区块标题使用细线分隔，提供安静的层级。
- 底部显示壁纸库位置；文件夹图标承担“迁移壁纸库”操作。

### 顶部工具栏

- 标题使用衬线体，副标题使用等宽字体。
- 搜索框为自绘表面：panel 背景、细线边框、聚焦时黄铜边框。
- 筛选/排序为安静文本菜单；视图切换为自绘双段控件。
- 主操作为黄铜“添加壁纸”。
- 内容宽度小于 870pt 时切换为图标紧凑布局，所有入口保留。

### 卡片

- 固定 190pt 宽；16:9 预览；6pt 圆角；1px 细线边框。
- 选中：1.5pt 黄铜边框 + 左上角黄铜勾选标记。
- 悬停：边框提亮到 `hairlineStrong`，不做位移或阴影。
- 文本区固定 56pt：
  - 名称（SF 13 medium，单行）
  - 类型 + 分辨率/格式（等宽 9–10pt）
  - 应用状态（黄铜点 + 显示器名称）；未应用时保持留白，把存储方式等细节留给检查器。
- 收藏星标使用黄铜，不使用系统黄色。
- 卡片是内容，不是按钮；点击区域覆盖整张卡片。

### 检查器

- 预览带细线边框；名称使用衬线体。
- 区块顺序：显示器 → 播放 → 适配方式 → 资源。
- 不使用 GroupBox；区块标题 + 细线 + 留白建立层级。
- 资源信息为两列账本：标签次级文字，数值等宽并可选择。
- 应用按钮为黄铜主操作，配置队列为细线次操作。

### 分页

- 顶部细线；页码等宽；当前页黄铜文字 + 黄铜下划线。
- “本页 N 项”和“第 X / Y 页”使用等宽数字。

### 空状态与引导

- 空状态使用一个 16:9 细线空画框作为记忆点，黄铜加号居中。
- 标题使用衬线体，说明保持一句话，按钮为黄铜主操作。
- 引导页复用同一套表面、细线和黄铜信号。

## 5. 动效与可访问性

- 仅保留控件自带的按下/悬停反馈；卡片悬停只改变边框颜色。
- 尊重“减少动态效果”；不添加自动播放的装饰动画。
- 所有图标按钮提供 `.help` 与可访问标签。
- 键盘焦点保持可见：自绘搜索框在聚焦时显示黄铜边框。
- 颜色对比满足深色背景下的正文可读性；黄铜只用于强调。

## 6. 避免的默认做法

- 不使用奶油色背景 + 陶土色强调。
- 不使用近黑 + 荧光绿/朱红。
- 不使用报纸式全细线、零圆角布局。
- 不使用统一圆角 + 统一阴影的 SaaS 卡片堆叠。
- 不使用全大写 eyebrow、字段间连续中点、装饰性编号。
- 不在按钮或链接文字末尾追加箭头符号。

## 7. 实现

- 颜色、字体、尺寸与按钮样式集中在 `Sources/WallpaperMac/AppTheme.swift`。
- 分页容量仍由 `WallpaperLibraryPageLayout` 计算，卡片宽度与 `gridTileWidth` 保持一致。
- 窗口最小宽度与固定工具栏高度由 `MainWindowMetrics` 与 `AppTheme.Metrics` 共同约束。
