# 快速开始

WallpaperMac 是本地 macOS 壁纸引擎：它可以将图片、视频或一个本地 HTML 项目应用到指定显示器，并提供壁纸库、分组、队列和菜单栏控制。当前最低支持 macOS 13。

## 1. 安装

### 使用 DMG

1. 从项目发布页下载与版本匹配的 `WallpaperMac-v<版本>-macOS.dmg`。
2. 双击 DMG，将 `WallpaperMac.app` 拖到 `Applications`。
3. 从“应用程序”启动 WallpaperMac。

项目的本地打包脚本使用临时（ad-hoc）签名；如果 macOS Gatekeeper 阻止首次启动，可在 Finder 中按住 Control 单击应用并选择“打开”，再确认继续。正式分发前请由维护者完成 Developer ID 签名和公证。

### 从仓库构建

```bash
swift build -c release
./scripts/package-release.sh
open dist/WallpaperMac.app
```

## 2. 首次启动

首次启动会要求选择或确认**壁纸库位置**。默认位置为：

```text
~/Library/Application Support/WallpaperMac/Library
```

壁纸库保存资源索引、显示器分配、分组、播放队列、缩略图和（在“复制到应用库”模式下）资源副本。请把它放在本地、可读写且不会被临时清理的位置；不要放在仓库工作目录、系统临时目录或会在重启后被清空的位置。

在“设置 → 壁纸库”中可修改位置。移动或更换磁盘后，如果出现失效资源，请重新选择库位置或使用应用内维护操作重新定位资源。

## 3. 导入壁纸

可将文件或目录拖到主窗口，或使用“导入壁纸”打开文件选择器。

| 类型 | 可导入内容 | 备注 |
| --- | --- | --- |
| 图片 | 常见本地图片文件 | 作为静态桌面壁纸显示。 |
| 视频 | 常见本地视频文件 | 使用 `AVPlayer` 承载，默认静音。 |
| 网页 | `.html` 文件或本地 HTML 项目目录 | 项目目录需要指定入口文件，优先识别 `index.html`。 |

导入时选择一种存储策略：

- **复制到应用库**：资源副本进入壁纸库，原文件移动、改名或删除后仍可使用；从 WallpaperMac 删除该项目时会删除应用托管副本。
- **引用原文件**：WallpaperMac 只保存原路径，不复制资源；从库中删除只会移除记录，绝不会删除你的原始文件。若移动磁盘或原文件，项目会显示为失效，需要重新定位。

## 4. 预览并应用到显示器

1. 在主窗口侧边栏打开“全部壁纸”或按类型、分组筛选。
2. 选择资源，右侧检查器会显示 16:9 横屏预览、资源信息和维护操作。竖屏素材会填充后裁剪到预览框，这不会改变实际壁纸文件。
3. 在检查器中选择目标显示器并点击应用；每块显示器都可以独立使用不同资源和播放队列。
4. 对视频和网页壁纸，可使用播放、暂停、静音、循环或重新加载等控制。

显示器暂时断开时，应用会保留分配记录。重新连接后，按界面提示恢复配置；如果无法匹配旧显示器，先暂停动态播放，再选择恢复到指定显示器或将其作为新显示器配置。

## 5. 使用分组与队列

- 右键单个卡片或列表项可添加到分组、添加到队列、应用到显示器、收藏、在 Finder 中显示或删除。
- 多选后可以进行批量分组与队列操作。
- 队列库可创建多个命名队列；“默认队列”固定存在，删除活动队列后相应显示器会自动回退。
- 每块显示器绑定一个活动队列，队列进度、播放/暂停状态和单项时长覆盖独立保存。
- 队列可以顺序或随机播放、循环或播放一次后停止，并可设置默认间隔、单项时长和转场。
- 如启用“视频播放完成后切换下一个壁纸”，视频结束时会推进队列；此模式不与视频循环同时使用，避免重复切换。

## 6. 菜单栏控制

应用运行后，菜单栏会显示 WallpaperMac 图标。菜单提供：打开主窗口、暂停/恢复动态壁纸、静音/取消静音、打开壁纸库、打开设置和退出。关闭主窗口并不等于退出应用；请使用菜单栏“退出 WallpaperMac”完全结束。

## 常见问题

### 重启后资源或壁纸库消失

检查壁纸库是否位于持久化路径，且磁盘在登录后可用。若此前选择了会被清理的临时目录，创建一个永久文件夹后，在设置中重新选择它，并重新导入或定位失效资源。

### 外部引用变成“资源丢失”

这是原始文件路径变化、移动磁盘未挂载或权限不足造成的。连接原磁盘、恢复文件位置，或用应用内重新定位功能指向正确文件。若希望避免这类问题，今后导入时选择“复制到应用库”。

### 网页壁纸无法加载样式或脚本

确认入口文件、CSS 与 JavaScript 使用相对路径，且资源文件都在被导入的本地目录内。先使用仓库提供的 [简单网页壁纸模板](web-wallpaper-template.md) 验证导入流程。

### 视频或网页仍在占用资源

先用菜单栏或检查器暂停动态壁纸，再更换或删除资源。队列切换、显示器断开和应用退出时，播放器会释放前一个资源；如果问题可复现，请按 [Issue 模板](../../.github/ISSUE_TEMPLATE/bug_report.md) 提供脱敏的最小复现步骤。
