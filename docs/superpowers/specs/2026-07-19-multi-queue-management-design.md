# WallpaperMac 多队列与右键管理设计

## 背景

当前版本把播放队列直接绑定到显示器：每块显示器有一份 `DisplayPlaybackQueue`，导致无法复用命名队列，也无法集中维护队列内容。新功能需要把队列提升为独立资源，同时保留每块显示器的活动队列、播放进度和显示器级规则覆盖。

## 方案比较

### 方案 A：队列库 + 显示器活动队列绑定（采用）

- `PlaybackQueue` 是独立的命名资源，保存队列项目、顺序、默认规则。
- `DisplayPlaybackAssignment` 保存显示器绑定的队列、当前索引、播放状态和规则覆盖。
- 同一队列可以绑定多个显示器；每个显示器独立保存进度。
- 优点：符合用户确认的模型，队列可复用，显示器差异清晰，迁移旧数据可控。
- 代价：需要新增持久化文件和从旧 `display-queues.json` 迁移。

### 方案 B：每块显示器复制一份队列

- 实现简单，但修改一个队列无法同步多个显示器，无法满足“队列库”。

### 方案 C：使用 SQLite 或 Core Data

- 适合更大规模查询，但当前本地单用户工具引入依赖和迁移成本过高。

## 核心模型

### `PlaybackQueue`

- `id: UUID`
- `name: String`
- `wallpaperIDs: [UUID]`，同一队列自动去重并追加
- `sortMode: QueueSortMode`：自定义、名称、类型、添加时间
- `playbackMode: QueuePlaybackMode`：顺序、随机
- `completionBehavior: QueueCompletionBehavior`：循环、播放一次后停止
- `defaultIntervalSeconds: Double`
- `transition: WallpaperTransitionEffect`
- `createdAt`、`updatedAt`
- `itemIntervalOverrides: [UUID: Double]`

默认队列固定为“默认队列”，通过 `isDefault` 标识，不允许重命名或删除。播放规则修改立即影响绑定显示器，但显示器覆盖优先。

### `DisplayPlaybackAssignment`

扩展现有显示器播放队列记录：

- `displayID`、`displayName`
- `queueID`
- `currentIndex`
- `isEnabled`
- `isPlaying`
- `policyOverride: DisplayPlaybackPolicyOverride?`

覆盖项按“显示器 + 队列”保存，切回队列时恢复；显示器断开重连时按稳定显示器 ID恢复。无法识别历史身份时暂停并要求用户匹配历史配置或创建新显示器配置。

## 持久化与迁移

- 新文件：`playback-queues.json`，保存队列库。
- 新文件：`display-playback-bindings.json`，保存显示器到队列的绑定和进度。
- 首次读取时兼容旧 `display-queues.json`：为每个旧显示器生成一个命名队列“显示器名队列”，并将该显示器绑定到该队列；如果没有队列则创建空的“默认队列”。迁移成功后写入新文件，保留旧文件作为备份，不删除。
- 删除壁纸记录时从所有队列移除 ID；如果当前播放项被移除，播放下一项；当前队列为空则切到默认队列；默认队列为空则停止并展示空状态。
- 外部引用删除只删除记录，不删除源文件；应用库副本删除副本。

## 右键和批量菜单

壁纸卡片支持单项和已选 N 项批量右键：

- 添加到播放队列：选择已有队列或新建队列
- 添加到分组：选择已有分组或新建分组
- 应用到显示器：仅单项可用
- 收藏/取消收藏
- 在 Finder 中显示
- 从队列中移除：选择队列；移除后提供撤销提示
- 从分组中移除
- 删除壁纸记录：批量操作需确认；托管副本删除实际副本，外部引用保留原文件

## 队列管理界面

- 左侧导航增加“播放队列”。
- 中央区域展示队列列表和队列详情；支持新建、编辑、复制、删除（默认队列不可删除）。
- 支持拖拽排序。自动排序下手动拖拽会切换为“自定义排序”。
- 支持独立弹出队列管理窗口。
- 创建队列时设置名称、播放顺序、循环策略、默认时长；创建后可编辑，立即生效。
- 新显示器自动绑定默认队列并开始播放；重新连接恢复历史绑定。删除活动队列时切到默认队列并继续播放。

## 播放策略

- 顺序和随机两种播放顺序。
- 循环或播放一次后停止。
- 队列默认时长，单项可覆盖；同一壁纸在不同队列中的覆盖独立。
- 加载失败自动记录原因并跳过到下一项。
- 队列内自动去重，批量添加按当前壁纸库排序追加。

## 验收场景

1. 空库中创建默认队列和命名队列，重启后仍存在。
2. 右键单项和批量项分别加入多个队列，队列内无重复且追加顺序正确。
3. 自动排序队列手动拖拽后切换到自定义排序。
4. 同队列绑定两块显示器，各自进度独立；切换队列立即生效并恢复该显示器 + 队列的覆盖设置。
5. 删除活动队列切回默认队列；默认队列为空时显示空状态。
6. 删除当前播放壁纸后跳到下一项；外部引用原文件仍存在。
7. 旧 `display-queues.json` 可以迁移到新结构且不丢失壁纸 ID、间隔、转场和当前索引。
