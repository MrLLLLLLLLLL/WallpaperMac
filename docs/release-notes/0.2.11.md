# WallpaperMac 0.2.11

WallpaperMac 0.2.11 引入每块显示器的“默认 / 隐藏”队列槽位、整库迁移与动态分页，并修正断开显示器与全屏应用的暂停行为。

## 动态分页

- 壁纸库与分组不再固定每页 20 项，而是根据窗口内容区域计算：网格按可见列数×行数，列表按可见行数决定每页容量。
- 窗口缩放时自动重新计算页容量，并尽量保留当前首个可见壁纸所在的页面。
- 单个壁纸卡片尺寸不随每页数量变化；卡片文本区固定高度，保证分页容量与实际可见区域一致。

## 窗口工具栏

- 壁纸库顶部工具栏固定为 76pt 高度，窗口缩放不会改变工具栏高度。
- 内容宽度不足时自动切换为图标紧凑布局，标题和副标题保持单行，不再因压缩换行。
- 窗口最小宽度提升到 1242pt；拖拽、辅助功能与程序化缩放都会夹紧到最小宽度，保证工具栏完整显示且控件不越界。

## 多显示器与系统暂停

- 已断开的显示器只保留后台分配与队列记录，不再出现在主窗口侧栏、检查器和显示器选择列表中；重新连接后按原记录恢复。
- 全屏应用只暂停该全屏窗口所在显示器的壁纸，其他显示器继续播放；退出全屏后仅恢复对应显示器，不影响用户在其他屏幕上的手动暂停。
- 显示器参数变化继续按屏差异协调：未变化的屏幕保持当前播放器与播放位置。

## 默认与隐藏队列槽位

- 每块显示器新增“默认模式队列槽 + 隐藏模式队列槽”：隐藏模式关闭时使用默认槽，开启后使用隐藏槽。
- 队列类型由是否包含隐藏壁纸动态决定；类型变化后需要手动重新指定槽位，避免误播不匹配的队列。
- 默认槽不允许包含隐藏壁纸。在隐藏模式下，可以先把隐藏壁纸加入普通队列，使该队列转为隐藏队列，再指定为隐藏槽。
- 默认队列中的壁纸被标记为隐藏时会自动移出，不会自动加入隐藏队列。
- 槽位解析在队列缺失、类型不匹配或已被删除时按“空槽”处理，不会静默播放其他队列。

## 壁纸库迁移

- 新增壁纸库迁移：把索引、分组、队列、显示器档案、隐藏壁纸密码验证值、`Assets/` 与 `Thumbnails/` 完整复制到新位置并切换。
- 迁移成功后默认保留旧库，并询问是否删除旧库；删除前仍可手动返回旧库确认内容。
- 迁移在后台串行执行，完成后刷新壁纸库与显示器分配，避免在主界面阻塞文件 I/O。
