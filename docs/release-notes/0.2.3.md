# WallpaperMac 0.2.3

发布日期：2026-07-24

WallpaperMac 0.2.3 修复部分可在普通播放器中播放、但导入后无法生成封面或作为视频壁纸加载的 HEVC MP4。

## 问题修复

- 修复使用 HEVC / H.265 `hev1` sample entry 的本地 MP4 在部分 macOS AVFoundation 解码路径中报“Cannot Open”的兼容性问题。
- 视频播放器、视频元信息读取和首帧封面提取统一使用已准备好的兼容播放路径，避免出现“能导入但无法加载为壁纸”的状态。
- `wallpapers.json` 保留用户选择的原始来源路径；新增的 `playbackURL` 仅在需要时记录 WallpaperMac 生成的播放代理，旧版 JSON 无需迁移即可读取。

## 存储与数据安全

- **复制到应用库**：仅在应用库的托管副本中将合法的 HEVC sample entry 从 `hev1` 调整为 `hvc1`。音频、视频码流和用户原文件均不重新编码、不受影响。
- **引用原文件**：绝不修改用户原视频；WallpaperMac 在壁纸库的 `VideoProxies/` 目录创建兼容副本，并仅将其用于桌面播放、封面和元信息读取。
- 删除外部引用的壁纸记录时，只删除应用生成的播放代理，原视频仍保留在原位置。
- 旧的外部引用在重新加载壁纸库时会自动补建缺失的兼容播放代理。

## 验证

- 核心回归测试覆盖托管副本规范化、外部引用原文件不变、兼容代理生成和删除时的代理清理。
- 使用实际 `hev1` HEVC 4K MP4 复现 AVFoundation 首帧提取失败，并验证规范化为 `hvc1` 后可以成功提取首帧。
- 发布产物为 `WallpaperMac-v0.2.3-macOS.zip` 与 `WallpaperMac-v0.2.3-macOS.dmg`。
