# WallpaperMac 0.1.1

## 发布范围

WallpaperMac 0.1.1 是当前可交付的本地 macOS 壁纸管理器版本，支持图片、视频和本地 HTML 网页壁纸。

## 发布检查

- 统一使用根目录 `VERSION` 文件中的 `0.1.1`。
- App Bundle 的 `CFBundleShortVersionString` 和 `CFBundleVersion` 均为 `0.1.1`。
- 发布压缩包名称为 `WallpaperMac-v0.1.1-macOS.zip`。
- 发布流程会校验内置 `Templates/SimpleWebWallpaper` 网页壁纸模板。
- 发布流程会检查 Info.plist、代码签名、ZIP 完整性和应用启动 smoke test。

## 已知边界

- 仍只支持本地 HTML 项目，不包含远程 URL、账号、云同步或在线素材市场。
- 当前使用 ad-hoc 签名，未使用开发者证书签名或公证。
