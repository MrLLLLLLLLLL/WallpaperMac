# WallpaperMac 0.2.0

## 发布范围

WallpaperMac 0.2.0 在图片、视频和本地 HTML 网页壁纸基础上，加入队列库、每显示器活动队列和壁纸右键管理，面向多显示器日常使用场景。

## 新增功能

- 播放队列库：创建、重命名、复制和删除命名队列；默认队列固定存在且不可删除。
- 队列播放规则：自定义排序、顺序/随机播放、循环/播放一次后停止、默认时长、单项时长覆盖和转场设置。
- 显示器独立绑定：每块显示器可以选择不同的活动队列，并独立保存当前项、播放状态和规则覆盖。
- 壁纸右键菜单：添加到播放队列、添加到分组、应用到显示器、收藏/取消收藏、在 Finder 中显示、从队列移除和删除壁纸记录。
- 批量管理：多选壁纸后可批量加入队列、加入分组、应用到显示器、收藏或删除。
- 持久化与迁移：队列库使用 `playback-queues.json`，显示器绑定使用 `display-playback-bindings.json`；旧版 `display-queues.json` 会在首次读取时迁移。

## 兼容性和安全语义

- 目标平台仍为 macOS 13+。
- 外部文件引用删除时只删除 WallpaperMac 记录，不删除用户原文件。
- 复制到应用库的托管副本删除时会清理应用库中的实际资源。
- 动态壁纸默认静音，失效队列项会自动跳过；全部失效时停止该显示器队列。
- 不新增远程 URL、账号、云同步或在线素材市场。

## 发布检查

- 统一使用根目录 `VERSION` 文件中的 `0.2.0`。
- App Bundle 的 `CFBundleShortVersionString` 和 `CFBundleVersion` 均为 `0.2.0`。
- 发布产物包括 `WallpaperMac-v0.2.0-macOS.zip` 和 `WallpaperMac-v0.2.0-macOS.dmg`。
- 发布流程会校验网页壁纸模板、核心行为测试、Debug/Release 构建、播放器 runtime matrix、App smoke test、Info.plist、代码签名和 ZIP/DMG 完整性。

## 已知边界

- 仍只支持本地 HTML 项目，不包含远程 URL、账号、云同步或在线素材市场。
- 当前使用 ad-hoc 签名，未使用开发者证书签名或公证。
