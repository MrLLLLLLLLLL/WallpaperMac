# WallpaperMac 0.2.6

WallpaperMac 0.2.6 引入应用内自动更新，并对崩溃安全、队列编辑、更新链路与存储健壮性做了系统性修复。

## 应用内自动更新

- 设置新增「软件更新」：检查更新、查看发布说明、下载并安装新版本，完成后应用自动重启。
- 完整性校验链：`SHA256SUMS` 流式比对 + Ed25519 域分隔数字签名（`WallpaperMac-update-v1`），缺失或无效签名即中止安装。
- 发布脚本 `build-release.sh` 缺少签名密钥时 fail-closed，拒绝产出可发布 zip；`WALLPAPERMAC_ALLOW_UNSIGNED=1` 仅供本地开发。
- 安装采用旁路脚本：等待当前进程退出后替换 `.app`、清除 quarantine、拉起新版；失败自动回滚到 `.previous`。
- 「启动时每日检查一次」真实生效，且不会被设置窗口关闭打断进行中的安装。

## 队列播放看门狗

- 未知时长视频不再被 300 秒强制截断。看门狗重定义为停滞检测器：帧心跳续期 60 秒窗口，另有 4 小时绝对硬顶。
- 视频播完回调携带播放会话令牌，旧播放器的迟到回调不会再造成队列双跳。

## 崩溃与数据安全

- 修复视频流式播放 `readFrame` 在 teardown/进程退出并发下越界崩溃。
- 修复队列编辑器保存丢失删除项与手工排序；手工编辑后排序模式固定为自定义。
- 修复多文件拖放只导入最后一个文件；按拖入顺序聚合。
- 遗留队列迁移改为 plan/marker 崩溃恢复协议：半迁移可续跑，已迁移用户的现代文件不被 legacy 覆盖。
- 元数据回填改为字段级补丁，不再用整档快照覆盖并发编辑（重命名、收藏等）。
- 删除壁纸先写索引再清理资源；孤儿清理严格限定 `Assets/{UUID}-` 命名空间。
- 损坏存档出现重复 ID 时保留首值，不再崩溃。

## 性能与体验

- 缩略图渲染路径引入缓存（path + mtime + size）与 ImageIO 头读取，大图库不再因同步解码卡顿。
- 更新下载使用系统传输并实时回报进度；解压/外部进程移出主线程。
- `ProcessRunner` 统一外部进程管理（stderr 落盘、超时 SIGTERM→SIGKILL），根治管道死锁。
- 菜单栏「暂停/恢复动态壁纸」标题随状态切换；相同文案 toast 不再被旧定时器误清。
- 目录判定改为文件系统元数据，拖入的无尾斜杠目录不再被误判。

## 验证

- `WallpaperMacCoreTests` 全量 85 项通过。
- `scripts/player-runtime-test.sh` 图片/视频/网页播放矩阵通过。
- `scripts/queue-memory-regression.sh` 队列切换内存稳定。
- `scripts/build-release.sh` 产出带 Ed25519 签名与 `SHA256SUMS` 的发布 zip。
- `scripts/update-artifact-smoke.sh` 校验真实 release 产物哈希与签名。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
