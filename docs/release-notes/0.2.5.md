# WallpaperMac 0.2.5

WallpaperMac 0.2.5 针对视频兼容性和“引用原文件”存储语义进行修复。

## 视频兼容播放

- AV1 等 AVFoundation 不直接支持的编码，通过内置 ffmpeg 解码后将视频帧流式送入壁纸播放层。
- App 内置兼容转换用 ffmpeg；开发环境可设置 `WALLPAPERMAC_FFMPEG` 覆盖可执行文件。
- 流式播放不生成完整播放副本，不把大型视频复制到用户自定义壁纸库或系统缓存；启动时清理旧版完整兼容播放文件。
- 当 AVFoundation 无法从视频提取封面时，使用 ffmpeg 提取首帧作为封面。

## 引用原文件

- 选择“引用原文件”时，源视频路径保持不变，不再复制到 `VideoProxies/`。
- 加载壁纸库时自动移除旧版本遗留的 `VideoProxies/` 副本。
- MP4 `hev1` 检测改为解析真实 sample entry，不再把压缩媒体数据中的同名字节误判为 HEVC。
- 修复异步安装 `AVPlayerLayer` 时未同步设置内容视图 bounds，导致视频壁纸窗口存在但播放画面不可见的问题。
- 设置中新增“壁纸点击效果”。启用后网页壁纸移动到桌面图标层上方并接收鼠标点击；关闭时保持原有点击穿透。
- 修复网页点击转发改为单次激活，暂停音乐后不会被第二次 click 立即恢复播放。

## 播放队列稳定性

- 修复自动队列切换用 `makeKeyAndOrderFront` / `NSApp.activate` 抢走前台应用焦点的问题，壁纸窗口改为 `orderFrontRegardless`。
- 修复兼容流式播放在视频循环后 PTS 被清零、画面卡在循环点的问题，循环时间轴保持单调递增。
- 修复“视频播放完成后切换下一个壁纸”在解码探测失败、ffmpeg 缺失或应用壁纸失败时队列永久停住的问题：失败路径会回报播放完成，并按视频时长增加看门狗定时器兜底。
- 修复视频循环时 `seek` 尚未完成就调用 `play` 可能导致播放器一直停在等待状态的问题。

## 验证

- `WallpaperMacCoreTests` 覆盖 AV1 兼容策略、真实 sample entry、外部引用无代理、历史代理清理和视频完成看门狗边界。
- `scripts/player-runtime-test.sh` 对视频壁纸窗口进行截图像素检查，确保播放层不是黑屏或零尺寸。
- `scripts/video-codec-runtime-test.sh` 使用真实 AV1 样本验证流式画面可见、源文件不被修改且不创建完整播放副本。
- `scripts/test-release.sh` 继续执行 Debug/Release、App/ZIP、播放器运行矩阵、App 冒烟和签名完整性检查。
