# WallpaperMac 0.2.8

WallpaperMac 0.2.8 新增 HTTP/HTTPS 网页壁纸和四种适配方式，并集中加固播放调度、网页生命周期、视频解码与自动更新安装。

## 网页壁纸

- 可通过“添加壁纸 → 导入网址”添加 HTTP/HTTPS 网页，壁纸库只保存网址，不复制站点资源。
- 在线页面在 WKWebView 中渲染；加载失败会显示提示，并以上限内的退避自动恢复。
- 页面脚本自动点击不会唤起外部浏览器；只有真实鼠标手势才能打开链接，且授权一次性、匹配目标网址。
- 暂停壁纸时使用 WebKit 媒体挂起能力，恢复时可释放并重建渲染内容。

## 适配方式

- 支持“填充、适应、拉伸、平铺”四种适配方式；图片、AVPlayer 与 ffmpeg 播放共用同一布局规则，平铺按素材原始尺寸重复且不重复解码视频。
- 每张图片或视频可在检查器中设置独立适配方式；不设置时跟随全局，全局默认仍为填充。
- 切换单项适配只更新布局，不重建播放器或重置队列进度。
- 修复 16:10 竖屏副屏以“填充”显示 16:9 横屏壁纸时的左右黑边；视频尺寸未知时不再把视口尺寸误作 ffmpeg 源画布。

## 播放与多显示器

- 修复手动暂停跨过计时后恢复不再推进队列的问题；暂停与系统挂起会冻结固定间隔、视频看门狗和硬截止时间，恢复时保留剩余时间。
- 原生 AVPlayer 以实际播放时间前进作为心跳，缺少时长元数据的长视频不再被看门狗提前切走。
- ffmpeg 解码器异常退出不再无限重启；正常退出先排空完整尾帧，暂停与销毁不会创建新解码进程。
- 显示器参数变化按屏差异处理：未变化的屏幕保持播放器与位置，几何变化只更新窗口，断屏保留队列配置并在重连时恢复。

## 导入、存储与队列

- 网页项目重定位保留用户选择的嵌套入口，不再静默改播 `index.html`。
- 单个 HTML 文件只复制并授权该文件，不再隐式处理父目录；导入确认页显示实际范围、文件数与估算大小。
- 队列文件读取失败时禁止用默认状态覆盖原文件，并提供“重新加载”入口；旧队列迁移不再被误判为已完成。
- 删除当前播放项后队列继续到下一项；删除顺序改为先提交索引、再清理文件。

## 自动更新与发布

- 更新安装先在应用同目录完成并校验临时 Bundle，再用 macOS 原子交换替换应用；失败可恢复旧版。
- 新 App 启动后必须回执一次性健康 token；超时、版本不符或回执错误会回滚。
- 同一 App 的更新使用跨进程锁，避免多实例同时替换或删除备份；弱网下载支持断点续传。
- 发布流程一次冻结 App，同源生成并验证 ZIP、DMG、签名和 SHA256SUMS；线上产物冒烟强制验签。

## 验证

- `WallpaperMacCoreTests` 全量 125 项通过。
- `scripts/test-release.sh` 覆盖核心测试、Debug/Release 构建、播放器矩阵、填充/平铺适配、视频编解码、网页生命周期、队列暂停、更新安装事务与 Bundle 检查。
- 在 1600×2560、旋转 270° 的竖屏副屏上验证图片、H.264 与 AV1 的填充覆盖及单壁纸适配覆盖。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
