# WallpaperMac 0.2.7

WallpaperMac 0.2.7 加固弱网环境下的应用内更新，并把播放队列的切换时机改为明确的二选一。

## 更新下载

- 支持断点续传：传输停滞（60 秒内平均低于 4 KB/s）或中途断开时，从断点继续而不是重新下载。
- 重试次数有上限，最终失败会说明是网络反复中断、下载停滞还是服务器错误。
- 设置中显示更新包大小与实时下载速度；失败后可直接「重试下载」，无需重新检查更新。
- 后台检查到新版本时，菜单栏显示更新徽标与「发现新版本」入口，不弹窗打断当前工作。

## 安全校验

- 每次安装前都会对完整落盘文件重新执行 SHA-256 比对与 Ed25519 签名校验，续传不会跳过任何一步。
- 校验或安装失败时删除残留文件与临时目录，绝不安装未完整校验的字节。

## 播放队列

- 切换时机改为二选一：「视频播完后切换」或「固定时长切换」。
- 选择「视频播完后切换」时，视频按实际播放结束推进；图片和网页壁纸没有结束事件，自动回退到固定时长，避免队列停住。
- 旧队列的布尔设置会在读取时自动迁移；新存档同时保留旧字段，降级到旧版本也不会丢失设置。

## 验证

- `WallpaperMacCoreTests` 全量 94 项通过。
- `scripts/test-release.sh` 通过：播放矩阵、AV1 兼容、流式内存回归、网页交互、应用冒烟与包体检查。
- `scripts/build-release.sh` 产出签名 zip 与 `SHA256SUMS`。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
