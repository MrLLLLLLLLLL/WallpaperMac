# WallpaperMac 0.2.1

发布日期：2026-07-20

0.2.1 聚焦壁纸资源可读性、视频封面和大壁纸库的加载体验，同时保持现有多队列和多显示器播放能力。

## 新增与优化

- 资源信息检查器显示文件格式、文件大小、像素分辨率、视频时长和原始路径。
- 图片和视频资源的元数据在后台读取，不阻塞壁纸库首屏加载。
- 视频优先读取文件内嵌 artwork 作为封面；没有内嵌封面时提取首帧，并保存到壁纸库的 `Thumbnails/` 目录。
- 壁纸库采用分页显示，每页 48 项；滚动到当前页底部后再加载下一页。
- 搜索、筛选、排序和侧边栏切换会重新从第一页开始，队列、分组、批量操作仍使用完整资源集合。
- 旧版本没有 `metadata` 字段的 `wallpapers.json` 可以继续读取，缺少的信息会在后台补齐。
- 资源重定位或删除时会清理 WallpaperMac 自己生成的旧封面；外部引用资源不会被误删。

## 验证

- `swift run WallpaperMacCoreTests`：核心测试通过。
- `swift build`：Debug 构建通过。
- `swift build -c release`：Release 构建通过。
- 发布脚本会继续执行网页模板校验、播放器 runtime matrix、App smoke test、Bundle/签名校验和 ZIP 完整性检查。
- `scripts/queue-memory-regression.sh` 用于确认队列切换后 RSS 和壁纸窗口数量不会持续增长。

## 兼容性与边界

- 支持 macOS 13+。
- 第一版仍只支持本地 HTML 项目，不包含远程 URL、账号、云同步或在线素材市场。
- 视频和网页壁纸默认静音，且继续按显示器独立管理播放状态。
