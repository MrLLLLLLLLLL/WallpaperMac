# WallpaperMac 0.2.4

发布日期：2026-07-24

WallpaperMac 0.2.4 聚焦大型本地壁纸库的操作响应速度。此版本不改变图片、视频、本地 HTML、分组和队列的数据模型；重点是把耗时文件系统工作从 SwiftUI 主线程移走，并消除多选分组时不必要的重复元数据读写。

## 性能修复

- 新增 `WallpaperStoreWorker` 串行后台 Actor。壁纸库加载、文件夹扫描、资源可用性检查、视频兼容播放副本准备、导入复制、删除、重新定位和 JSON 保存均在该 Worker 中完成；主界面只接收已经解码的壁纸库快照。
- 多选壁纸加入分组、移出分组时，`WallpaperStore` 现在一次读取并一次写入 `wallpapers.json`，不再按选中资源数量重复执行完整的读写循环。
- 打开导入面板后，图片/视频/网页类型识别和本地 HTML 入口文件枚举会先在后台完成；导入 Sheet 的 SwiftUI 重绘不再触发递归目录扫描。
- 刷新壁纸库时，只有资源可用性或视频 `playbackURL` 实际变化才会原子写回元数据，避免大型壁纸库每次打开都产生无意义的 JSON 写盘。

## 交互与数据安全

- 所有库文件操作仍由单一 Worker 串行化，避免同时导入、删除或分组时产生并发写入竞争。
- UI 状态更新继续在主线程执行；加载过程中旧任务会被取消或忽略，避免过期加载结果覆盖当前库页面。
- 修复启动阶段多次加载壁纸库时，后一次加载可能取消显示器分配与活动队列恢复回调的问题。
- 设置窗口增加“关于 WallpaperMac”分组，版本与构建信息读取 App Bundle 的 `Info.plist`，与安装包版本保持一致。
- 托管副本、外部文件引用、视频播放代理及分组持久化格式保持兼容，已有 `wallpapers.json` 无需迁移。

## 验证

- 核心测试新增批量分组持久化回归覆盖，并通过 37 项 WallpaperMacCoreTests。
- 完成 Debug/Release SwiftPM 构建及本地 App/ZIP/DMG 发布校验。
- 本版本仅进行本地 Git 提交，不推送到 GitHub。
