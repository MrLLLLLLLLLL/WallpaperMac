# WallpaperMac 0.2.12

WallpaperMac 0.2.12 统一主窗口、检查器、队列管理、设置与引导的视觉语言，保留 0.2.11 的动态分页与固定工具栏行为。

## 黄铜接触印相表

- 新的视觉方向以壁纸缩略图为主体：石墨背景、暖白文字、细分隔线，黄铜色只用于选中、当前页与主操作。
- 标题使用系统衬线体（中文回退到宋体），正文与控件使用 SF Pro，尺寸、分辨率与页码使用等宽数字。
- 侧栏、内容区和检查器共用 76pt 顶部基准线；选中项使用 2pt 黄铜竖条与 12% 黄铜底色，不再使用整块蓝色胶囊。

## 主窗口

- 壁纸卡片固定 190pt 宽，6pt 圆角与 1px 细线；选中时显示黄铜描边与勾选标记，悬停只提亮边框；收藏星标改为黄铜。
- 卡片文本区固定 56pt：名称、类型与分辨率、应用状态分层显示；未应用时保持留白，存储模式等细节留给检查器。
- 侧栏为分类、分组和显示器增加等宽计数；分组与显示器区块使用细线和安静的分区标题。
- 空状态改为 16:9 细线空画框；筛选无结果时可以直接清除筛选。
- 顶部工具栏保留完整/紧凑两种布局、固定高度和 1242pt 最小窗口宽度。

## 检查器

- 顺序调整为显示器 → 播放 → 适配方式 → 资源，优先呈现“应用到哪里”。
- 移除 GroupBox，使用区块标题、细线和表面卡片；资源信息为两列账本，数值使用等宽字体并可选择复制。
- 顶部新增收藏按钮；应用按钮为黄铜主操作，队列与维护操作使用安静按钮。

## 队列管理、设置与引导

- 队列库改为与侧栏一致的自绘选中行；队列标题使用衬线体，播放规则、槽位和队列内容使用统一表面卡片。
- 设置窗口使用黄铜 tint；更新提示、登录项状态与关于信息保持原生表单结构。
- 引导页、权限状态和功能卡片复用同一套颜色、细线与主按钮。

## 验证

- `swift build` 通过。
- `WallpaperMacCoreTests` 全量 150 项通过。
- `scripts/test-release.sh` 完整发布闸门通过（`ALL_RELEASE_TESTS_PASSED`）。
- 实际窗口验证：1440×900 完整布局、1242×650 最小布局均无控件越界；1440 与 1600 宽卡片尺寸保持一致。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
