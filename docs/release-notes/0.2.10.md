# WallpaperMac 0.2.10

WallpaperMac 0.2.10 修复隐藏壁纸解锁后的暂停状态，并加固应用内更新的安装与健康确认流程。

## 隐藏壁纸

- 修复输入密码解锁隐藏壁纸后，壁纸仍停留在暂停状态的问题。
- 锁定隐藏壁纸时会记录每块屏幕挂起前的播放意图；解锁后只恢复原本正在播放的屏幕，不会把手动暂停的屏幕改为自动播放。

## 应用内更新

- 安装完成后优先直接启动新版本，确保更新健康 token 参数送达；`open` 仅作为回退。
- 健康等待上限从 10 秒延长到 30 秒，降低首次启动较慢时被误判为失败的概率。
- 安装脚本把输出写入 staging 目录的 `install.log`，失败后便于诊断。
- 回滚后优先直接重新启动旧版本。
- 安装前读取磁盘上 App 的实际版本；如果已经是目标版本或更高，不再执行同版本替换。
- 这些改动会让后续版本使用更可靠的安装器；从 0.2.9 更新到 0.2.10 时仍由 0.2.9 自带的安装器执行。如果该次更新失败，可手动下载 DMG 安装。

## 验证

- `WallpaperMacCoreTests` 全量 141 项通过。
- 更新原子交换、健康握手、安装锁和产物故障注入冒烟通过。
- 使用只有隐藏视频的队列验证：锁定时不上屏，解锁后恢复播放且状态为 `playing`。
- `scripts/test-release.sh` 覆盖核心测试、Debug/Release 构建、播放器矩阵、填充/平铺适配、隐藏壁纸队列跳过、视频编解码、网页生命周期、队列暂停、更新安装事务与 Bundle 检查。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
