# WallpaperMac 0.2.2

WallpaperMac 0.2.2 聚焦资源预览比例、队列视频切换规则和分组页面的大库加载体验。

## 主要变化

- 资源卡片和资源信息检查器统一采用 16:9 横屏预览框。
- 非 16:9 的图片、视频和网页资源使用填充裁剪方式展示，避免预览区域因素材比例变化而跳动。
- 修复竖屏视频缩略图仍按原始比例撑高卡片和检查器的问题，改用独立的固定 16:9 预览容器。
- 播放队列新增“视频播放完成后切换下一个壁纸”独立配置。
  - 开启后，视频播放到结尾时切换到队列中的下一项。
  - 关闭时保持原有按队列间隔定时切换行为。
  - 开启该配置时不会再对视频应用循环播放，避免视频结束事件和循环逻辑重复触发。
- 分组页面与壁纸库共用每页 48 项的分页契约和滚动加载逻辑。
- 队列设置、视频完成切换配置和分页规则均保留现有多显示器活动队列模型。

## 兼容性

- 修复“登录时启动”设置在较严格 Swift 并发检查下的主 Actor 隔离编译错误。

- 继续支持 macOS 13+。
- 旧版 `playback-queues.json` 缺少视频完成切换字段时，默认按关闭处理，保持升级后的原有定时播放行为。
- 旧版 `wallpapers.json`、外部引用资源和应用库副本不受影响。

## 验证

- 核心测试覆盖 16:9 预览契约、分页边界、队列配置编解码和旧队列兼容。
- 发布构建会生成 `WallpaperMac-v0.2.2-macOS.zip` 与 `WallpaperMac-v0.2.2-macOS.dmg`。
