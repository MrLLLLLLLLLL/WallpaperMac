# WallpaperMac 0.2.9

WallpaperMac 0.2.9 增加密码保护的隐藏壁纸，并修复多显示器重启后播放队列互换的问题。

## 隐藏壁纸

- 图片、视频和网页壁纸都可以标记为隐藏；关闭“显示隐藏”开关后，隐藏项不会出现在主库、分组、检查器或队列编辑器中。
- 混合队列播放时自动跳过隐藏项；全部为隐藏项的队列不会上屏，但队列配置和进度会保留。
- 关闭开关会立即移除正在显示的隐藏壁纸；固定分配保留记录，解锁后可恢复。
- 首次隐藏壁纸需要设置密码，之后每次打开“显示隐藏”开关都需要输入密码；关闭开关即重新锁定。
- 密码验证信息保存在壁纸库的 `hidden-wallpapers-lock.json`，使用 PBKDF2-HMAC-SHA256，不保存明文密码。
- 隐藏只是应用内显示层的遮蔽，不加密文件、缩略图或索引；不提供密码找回，删除库内锁文件可重置密码验证信息。

## 多显示器

- 每块屏幕改用 ColorSync UUID 作为稳定标识保存壁纸分配和播放队列，重启后不再因 `CGDirectDisplayID` 重新分配而互换队列。
- 旧 `display-N` 记录优先按显示器名称迁移；无法匹配的记录和离线显示器档案会保留。
- 显示器档案记录 UUID、vendor、model、serial，UUID 缺失或变化时仍能匹配原档案。

## 界面

- 主库头部控件保持单行对齐，隐藏开关改为固定尺寸图标与小开关组合。

## 验证

- `WallpaperMacCoreTests` 全量 138 项通过。
- `scripts/test-release.sh` 覆盖核心测试、Debug/Release 构建、播放器矩阵、填充/平铺适配、隐藏壁纸队列跳过、视频编解码、网页生命周期、队列暂停、更新安装事务与 Bundle 检查。
- 在真实桌面验证了密码设置/解锁、错误密码、隐藏/取消隐藏、关闭开关后立即下屏，以及混合/全隐藏队列的运行时行为。

macOS 13+；App 采用 ad-hoc 签名。首次启动若被 Gatekeeper 阻止，请在 Finder 中按住 Control 单击应用并选择“打开”。
